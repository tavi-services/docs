## Connection

Send credentials in the `X-Tavi-API-Key` header. Store and use the key on your backend.

Partner keys are scoped to permitted organizations, sites and operations. Confirm credentials, rotation, expiry and rate limits during setup.

## Work orders and messages

Paths are relative to `/api/v1`.

| Method | Path | Purpose |
| --- | --- | --- |
| POST | `/locations/client/` | Create a site |
| GET | `/locations/` | List permitted sites |
| POST | `/jobs/client/` | Create a work order |
| GET | `/jobs/client` | List; filter by `status` or `location_id` |
| GET | `/jobs/client/{job_id}` | Read job, visits, quotes and payment information |
| GET / POST | `/jobs/{job_id}/chat` | Read timeline / send a customer-side message |
| POST | `/attachments/upload/job/{job_id}` | Upload media to an existing job |
| GET | `/jobs/client/{job_id}/options/{letter}/quote-pdf` | Read a published quote |
| POST | `/jobs/client/{job_id}/options/{letter}/approve` | Approve the price and scope shown |

## Create a work order

```http
POST /api/v1/jobs/client/
X-Tavi-API-Key: <partner-key>
Idempotency-Key: create-request-1048
Content-Type: application/json
```

```json
{
  "location_id": "11111111-1111-4111-8111-111111111111",
  "trade": "PLUMBING",
  "description": "Faucet leaking below the sink",
  "deadline_date": "2026-10-28",
  "external_id": "request-1048",
  "contact": {"name": "Alex Example", "phone": "+12025550123"},
  "priority": "standard",
  "authorization": {
    "mode": "nte",
    "scope": "Diagnose and repair the faucet leak",
    "limit": {"amount_minor": 30000, "currency": "USD"},
    "actor_id": "approver-17",
    "recorded_at": "2026-10-27T15:00:00Z",
    "evidence_reference": "consent-1048"
  }
}
```

This example requests a plumbing repair with a $300 spending limit. `location_id`, `trade`, `description` and `deadline_date` identify the request. `authorization` records the approved scope, limit and approver. Optional fields include unit, access notes and purchase-order reference.

`contact.phone` is required so Tavi can call or message the customer directly. `contact.email` is optional. `external_id` is your immutable request ID, unique within your integration. Responses include it alongside the Tavi job ID. `amount_minor` uses the smallest currency unit: `30000` is $300 in USD.

## Documents and decisions

All paths below start `/jobs/client/{job_id}`.

| Path | Method | Request / result |
| --- | --- | --- |
| `/files?category=…` | GET | Categorized intake, before/after and signature evidence |
| `/invoices` | GET | Itemized invoice, PDF, balance and settlement state |
| `/answers` | POST | Question ID + answer + optional evidence |
| `/quote-decisions` | POST | Quote/version, option, decision, actor and authority; includes NTE increases |
| `/reschedule-requests` | POST | Requested windows + reason; asynchronous confirmation |
| `/cancellation-requests` | POST | Reason; Tavi confirms the cancellation outcome asynchronously |
| `/completion-reviews` | POST | Completion ID, actor, time, confirmed/not-fixed and evidence |
| `/issues` | POST | Service/billing/support issue, optional invoice reference |
| `/events` | GET | Replay retained events after a sequence/cursor |

Record the selected rate-card service or quote, decision and authorized spending limit against the work order.

## Reliable requests

- **Duplicates:** idempotency keys replay identical requests and reject changed bodies. External-ID uniqueness prevents duplicate jobs beyond the key-retention window.
- **Lists:** list pagination uses `skip` and `limit` (default 50, max 500); the chat timeline uses its own cursor.
- **Errors:** preserve JSON `detail`; validation commonly returns `422`, conflicts `409`.
- **Retries:** back off on transient failures, preserve the idempotency key, and refresh after a stale-quote conflict. Show a retrieval error when a read fails.

Upload photos against the Tavi job ID. Confirm when a request is ready for dispatch and agree supported media types, sizes, categories and retention during setup. Protect media with authenticated or expiring links.
